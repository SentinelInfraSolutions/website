# Sentinel Infrastructure Solutions Website v8 — Custom Hero Illustration

This release installs the custom Sentinel cybersecurity hero artwork.

## What changed

- Replaced the simple shield-and-card hero graphic with a custom branded illustration.
- Added a web-optimized WebP image for faster loading.
- Added subtle floating and glow animation.
- Added reduced-motion support for accessibility.
- Kept the official transparent Sentinel shield in the header, About section, and favicon system.
- The new illustration is decorative and does not replace the approved company logo.

## Upload

1. Extract this ZIP.
2. Open the GitHub `website` repository.
3. Choose **Add file → Upload files**.
4. Upload every file from inside the extracted folder.
5. Commit with: `Add custom animated hero illustration`
6. Wait for Cloudflare Pages to deploy.
7. Open the newest `.pages.dev` deployment and press **Ctrl + Shift + R** once.
