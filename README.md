# Sentinel Infrastructure Solutions Website

Official static website for Sentinel Infrastructure Solutions.

## Cloudflare Pages settings

- Framework preset: None
- Build command: leave blank
- Build output directory: `/`
- Production branch: `main`

## Deployment

Upload all files and folders from this package to the root of the GitHub `website` repository.
Cloudflare Pages will automatically deploy every commit to `main`.

## Initial files

- `index.html` — homepage
- `styles.css` — responsive site design
- `script.js` — mobile navigation and copyright year
- `privacy.html` — basic privacy notice
- `assets/` — SVG logo and favicon
- `robots.txt` and `sitemap.xml` — search engine basics

The SVG mark included here is an original web-ready approximation based on the established
shield/city/circuit brand concept. It can be replaced later with the official transparent logo file
without changing the page structure.
